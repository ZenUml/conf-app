Use their names: Diagram and Board. Keep them off the title field.

The official Confluence app’s slash menu on lite-stg tonight is Draw.io Diagram and Draw.io Board. Space nav is draw.io Diagrams and Whiteboards. The two chromes are Atlas (menus, grid, shape libraries) and Sketch (hamburger, no grid, slim left rail).

Diagram | Board picks which editor chrome loads — it is not the document name. TITLE already owns naming (AI sparkle, our label, dismiss). Those are different jobs; do not merge them into one bar. Center the mode switch on the menubar — same row as menus and TITLE, but in a notch pill that hangs from the top edge so it reads one level above both.

The control

RuleWhy, from the real UI
Labels: Diagram | Board Those are the slash-menu names on lite-stg. Do not use Graph | Board (Graph is the product). Do not use Atlas | Sketch (theme names, not user-facing).
Menubar center — notch pill, separate from menus and TITLE Mode picks chrome (sketch=1 reload); menus are actions; TITLE names the document. Three different jobs → three zones on one row. Center a white notch pill (top flush, rounded bottom, shadow) so it reads as the layer above File/Edit and the title field. TITLE keeps its existing right overlay.
No extra click on insert Forge does not tell us the user typed /board. Default Diagram (or last-created theme). Board is one click on this control.
Board reloads the iframe with sketch=1 That is how their Board macro is implemented. Same mxfile. Existing shapes keep styles.
On Board chrome, hide DrawIO’s filename box Their Board puts a filename field in the top bar. We already name the document in TITLE. Two name fields would sit in the same band.

What we are not doing

  • A fifth slash-menu item named Board (DrawIO).
  • A Sequence-style type tab. Those tabs switch engines. This switch only changes chrome.
  • A blocking create chooser over this editor.
  • Restyling existing shapes when the user flips Diagram → Board.
Slash match for /board on a title Graph / Board (DrawIO) is still unverified. Rename on staging and type it before we treat the title as discoverability. Live slash tonight already lists Draw.io Board as its own row — that is their app, not ours.
