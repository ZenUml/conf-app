下降时间:2023-11 第三周开始,2024-01 第一周到底。月度 2023-12 = 2,619 次 → 2024-01 = 516 次(−80%),之后持续走低到 2026 年的每月约 130 次。

能直接观测到的:(1)Doc 空间 34 个页面的周浏览量在 2023-12-23 周 318 → 12-30 周 187 → 2024-01-06 周 61,此后不再回升;上一年同样的假期低谷(2022-12-31 周 136)在一月恢复到 131 / 259 / 167 / 202。(2)下跌集中在"从空间首页进入"的那部分流量:首页 2023 年 7,969 次 → 2024 年 1,177 次(−85%),从首页导航才能到达的 Basic Concepts / FAQs −90% / −94%;靠内容查询到达的 Sequence diagram syntax 只降 −48%。(3)2023-12-26 zenuml.com/docs 上线,GA4 中 /docs 2023-12 为 134 次,2024-01 为 7,340 次。(4)Confluence 分析没有来源(referrer)维度,Doc 空间的访问来自哪里无法直接测得。

结论(推断,不是观测):Doc 空间 2023 年的流量主要来自站外入口落在空间首页(品牌搜索、各处 "Documentation" 链接),2023-12 之后这部分入口转到了 zenuml.com / zenuml.com/docs。已量化并排除的入口:应用内链接(编辑器帮助按钮、Get Started 页、仪表盘)量级为每月几十到几百次,且 2024-05 之前一直指向 Doc 空间;Marketplace 文档链接从未改动,列表页每月约 100–200 次浏览;zenuml.com 换站(2023-10-21 至 11-10)把首页两个文档入口从 Doc 空间改指站内 /docs,前后周均值只差 5%,且 GA4 显示 /docs 作为落地页 2024 Q1 只有 101 次(首页 7,255 次)。削弱推断的事实:zenuml.com 2024 Q1 的会话来源中搜索引擎只占 26%(google 20%、bing 4%、baidu 1%),直接访问 42%,垃圾 referral 18%;Google 今天对 "zenuml sequence diagram syntax" 仍把 Confluence 页排在第一位。Doc 空间 2023 年流量的真实来源:原因未查明。

3. 原因拆解

主因(推断)2023-12-26

zenuml.com/docs 用同一套内容上线,站外入口转移 ZenUml/docs 提交记录 GA4 周序列 来源无法直接测得

Doc 空间 2023-12-16 至 12-19 新建的页面(What is ZenUML?、Quick Start、Language Guide、participant types 等)在 2023-12-26 以同名 Markdown 提交到 ZenUml/docs 仓库(commits 5124f21、205d0cb、fa58fda、eb9ae98),同日启用 gtag(6c2b923)。GA4 中 /docs 路径 2023-12 为 134 次,2024-01 为 7,340 次。Google 对 site:zenuml.atlassian.net 目前仍有收录,但同内容已由 zenuml.com/docs 承接。

与序列的对应:12-23 周 318 → 12-30 周 187 → 01-06 周 61,之后 1 月各周 92 / 97 / 72,不再回升。排除季节因素:上一年同样的假期低谷(2022-12-31 周 136)在 2023-01 的各周为 131 / 259 / 167 / 202,完全恢复。各页面同步下跌,包括与应用无关的 ZEN 空间 Case Study 页(2023-11 第三周 48,2024-01 起为 0)。

证据强度。Confluence 分析没有来源维度,"流量迁移"是推断,依据是时间对应、承接方的量级和下跌的页面分布(首页入口 −85%,内容页 −48%)。zenuml.com 这一侧能看到的来源(GA4,2024 Q1,9,389 个会话):(direct) 41.8%、google 20.4%、bing 4.1%、baidu 1.4%、t.co 3.2%、modeling-languages.com 1.6%,垃圾 referral(news.grets.store、rida.tokyo、static.seders.website)18%;没有来自 zenuml.atlassian.net 或 marketplace.atlassian.com 的会话。应用内指向 zenuml.com/docs 的链接 2024-05-09 才出现,2024 Q1 的 /docs 访问与应用无关。Google 今天对 "zenuml sequence diagram syntax" 仍把 Confluence 页排在第一,对内容查询的承接没有发生;推断只对"落在空间首页的品牌/链接入口"成立。

假设

Doc 空间 2023 年的匿名流量主要来自站外(搜索引擎与外部链接) 未直接验证

支持:首页累计 18,862 次浏览,登录用户只有 48 人,流量几乎全部匿名;应用内、Marketplace、zenuml.com 三个已知入口都量化为小;周序列有假期低谷,与人类访问的季节性一致(爬虫不会)。无法验证:zenuml.atlassian.net 不是我们的 Search Console 资源,Confluence 不记录 referrer,2023 年之前的站点设置变更(匿名访问、搜索引擎收录开关)无审计日志可查。今天的搜索结果(2026-08-22,WebSearch):查询 "zenuml" 和 "zenuml documentation" 的前 10 条都没有 zenuml.atlassian.net(落到 zenuml.github.io、zenuml.com、docs.zenuml.com、zenuml.com/docs、Marketplace);查询 "zenuml sequence diagram syntax" 的第 1 条仍是 Confluence 的 Sequence diagram syntax 页。与"首页入口 −85%、内容页 −48%"的页面分布一致,但这是今天的状态,推不出 2023-12 当时的变化。其他未排除的解释:搜索引擎对 zenuml.atlassian.net 的收录或排名在 2023-12 发生变化(含 Google 对品牌查询改为落到 zenuml.com);Atlassian 对匿名浏览计数口径的历史变化(今天匿名且未同意 cookie 的访问被计数,2024 年当时是否如此无法回溯)。

降级2023-10/11 换站

zenuml.com 换站,首页两个文档入口从 Doc 空间改指 /docs — 对周浏览量的影响 −5% Wayback 快照 周序列

旧站(WordPress,标题 "ZenUML - Diagram-As-Code Solution")首页有两处指向 zenuml.atlassian.net/wiki/spaces/Doc/overview:导航栏 "Documentation"(nav#primary-site-navigation > li#menu-item-1436 > a.menu-link)和首屏按钮 "Read Docs"(a#btn_secondary_read_docs)。2022-05-24 快照 1 处,2022-12-01、2023-06-01、2023-09-01、2023-10-02、2023-10-21 快照各 2 处。

新站(2023-11-10 快照起)保留了同样两个位置,href 改成站内路径:导航栏 "Docs" → /docs,首屏按钮沿用同一个 DOM id btn_secondary_read_docs,文案 "Docs",href /docs(2024-01-23 快照与今天一致)。所以这两个入口是改指,不是删除;新站不再有任何指向 Doc 空间的链接。

但序列上没有对应的台阶:换站前 11 周(2023-09-02 至 11-11)6 页合计周均 402,换站后 4 周(12-02 至 12-23)周均 381,差 5%;中间 11-18 / 11-25 两周反而出现 753 / 619 的孤立峰值(原因未查明)。Google 2023-11 核心更新(11-02 至 11-28)也落在这一窗口,同样没有对应的台阶。GA4 也显示这条路径量小:新站首页 / 2024 Q1 有 7,255 次落地会话,而 /docs 作为落地页只有 101 次,/docs 的浏览量主要来自搜索直接落到具体文档页(/docs/tutorials/condition-and-loops-in-sequence-diagrams 168 次落地)。结论:zenuml.com 首页导流到文档的份额本来就小,这两个入口的改指不是下降的主因。

7. 边界

  • Confluence 分析不提供来源(referrer)维度,各入口的占比无法直接测得;"主因"的判断依据是入口变更时间与序列拐点的对应,以及 zenuml.com/docs 在 2024-01 承接的量级。

  • 2024-08 Sequence diagram syntax 页单月 686 次、2024-07 ZEN NTLM 页 697 次为孤立峰值,未纳入结论;原因未查明。
  • 本报告未做任何改动;两处仍指向 Doc 空间的应用内入口(Forge Get Started、首页 feed 卡片)是否改指 zenuml.com/docs,由你决定。
