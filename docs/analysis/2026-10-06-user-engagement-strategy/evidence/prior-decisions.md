## 2. CONSTRAINTS (standing rules)

1. **In-product levers first, no cold outreach.** Owner rule; correction 2026-06-15: Marketplace API does return technical/billing contact emails, so outreach is technically possible. The unresolved question: whether Atlassian Marketplace partner terms and privacy law permit using those contacts for sales or marketing. Never assert "fine" or "impossible"; ask the owner. Source: memory feedback_no_outreach; peng-profile "in-product, not outbound (gated by Atlassian Marketplace terms)".
2a. **No adoption emails to license technical contacts** (they are procurement, not team practice). Transaction moments (JSM threads, grace) still go through them. Source: project_c_tier_activation_jtbd item 1; c-tier research section 6 ("no adoption emails, no outreach").
2b. **Do not contact inactive paying tenants** (any message, including replies, courtesy closes; a JSM resolve also emails). Parked as "inactive payer". Exceptions: tenant reached out first, active payer, free tenant. Source: feedback_no_contact_inactive_payers; operating-model focused-clients.md (paid-inactive: retain, never disturb).
2c. Focus rule: spend effort on paid-or-active accounts; drop non-paying and inactive. Source: focused-clients.md.
3. **Forge versions.** Major (admin re-consent): any scope add/swap/remove, new `dynamic` web triggers, licensing/providers/remotes changes. Forge has no optional scopes. Minor (auto-upgrade): egress/CSP changes (Connect-migrated apps), new modules without scopes, trigger event-list edits. The remote-storage `inScopeEUD` classification is unknown until the staging deploy output is read. Source: root CLAUDE.md "Forge app versions"; README A12.
4. **Lite Forge flag cap 10 per app.** Last Console-verified 8/10 on 2026-08-27; code since added `create-guide-enabled` (and `ai-chat-repair-enabled` exists in code), so current count is UNKNOWN from my reads (the brief says 10/10). Deleting a flag requires: code gate removed and released everywhere, Console list read for the count, per-deletion owner confirmation. Source: memory reference_lite_flag_cap_state, feedback_flag_deletion_confirm; aiTitleFeatureFlag.ts.
5. **Forge Functions GB-seconds (free tier 100,000/app/month).** Anything running per page view or hourly per space is a cost risk: 4.15M content views/month; June 2026 incident (page-view trigger about 98% of compute); the hourly byline sweep was the top GB-s source (145k invocations, P50 over 4 s) and was removed 2026-10-02. A trigger forwarding to a remote bills as sync. Per-macro remote resolver runs on Cloudflare, not billed here. Source: forge-functions-cost skill; byline nudge design section 5; commit cddb40917.
6. **No customer data in any codebase** (public repo or private submodule); pilot artifacts in git-ignored local data. Client names, cloudIds and customer page titles never in public files. Source: memory feedback_no_customer_data_in_codebase; root CLAUDE.md client-privacy.
7. **Confluence is the system of record** for diagram bodies; D1/KV must not be required storage or recovery; no staging of bodies awaiting a page. Rendering must not depend on our backend. Source: root CLAUDE.md "Content management"; headless MCP design decision 4.
8. **Lite paywall.** Policy: default-on with `PAYWALL_EXEMPTIONS` (17 entries on 08-22, 19 domains by 09-07), fail-open on missing config, 45-day suppression while a Full/Diagramly install is inside its window (`paid_rail`). Thresholds: inline warning at 85 macros per space; banner and gate at over 100 per space (banner strictly >100, no 85-99 band). Hard edit-block retired 2026-09-06 (#617): non-blocking, 3 continue attempts (was 15), 7-day snooze + impression taper (1st immediate, 2nd/3rd >=24h, 4th+ >=7d). A 500-macro threshold is proposed, not shown adopted. Never touch two named large exempt/trial tenants (CSS enrollment framework). Free paths: Bundle $299/space/year (no site admin needed) and Full (needs site admin). Source: docs/features/paywall.md; README paywall bands (50-84: 74 spaces; 85-99: 24; 100-149: 23; >=150: 32); paywall-followup report.
9. **Solo founder capacity.** One person is engineer, releaser, analyst, support, growth. Effort split about 84% engineering vs about 10% revenue; target lanes Revenue about 25% (floor), Incident <=25% (cap), Feature about 35% that ships, Tooling about 15%. Rules: every Revenue/Feature item needs a "done and live when [metric] changes" sentence and a kill date; no item "continuing" three days in a row; max 3 lanes per day, one item per lane; stop "designed across many sessions" and "built then reverted" work. Largest waste is unshipped effort. Source: operating-model/README.md; peng-profile.md.
10. **Release order Diagramly (canary) then Lite (same SHA), then Full no sooner than 7 days after Lite; AsyncAPI independent.** Releases only on explicit trigger; staging deployed only by CI from a pushed branch (no local `forge deploy` to staging); prod flags/secrets/KV need explicit go-ahead; Lite release pipeline about 4-5 min. Source: root CLAUDE.md; memory feedback_no_implicit_release, feedback_deployment_discipline.
11. **Events before code.** Any feature lists its Mixpanel events (catalog.ts, types.ts) as the first commit; "signal is not result" rule: clicks and opens are not creates; "first creator" only since 2026-04-18. Source: root CLAUDE.md; c-tier research section 1.2.
12. **Platform facts that bind design.** Forge iframe has no `allow-popups`; every outbound link must use `openUrl()`. Modal sizing/Escape behaviour per create-guide doc. Forge cannot flag-gate a manifest module; dark launch needs displayConditions or a property gate. Byline iframe mounts on click only, so impressions are not observable. Source: memory reference_forge_iframe_no_allow_popups; lite-byline-activation-design.md Phase 0.
13. **Agent Link design lock.** The minted short-lived token is the feature; never propose user-supplied Atlassian API tokens as a smaller slice. Live relay stays; headless actor uses our own OAuth server (ADR 0008). Source: ADR 0003, 0008; memory feedback_agent_link_minted_token_is_the_point.
14. **Public-issue hygiene.** No public issues for sensitive topics (use the private tracker). Source: memory MEMORY.md index.
