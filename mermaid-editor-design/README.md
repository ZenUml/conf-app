# Mermaid 文本编辑器设计

这个子项目聚焦桌面版 Confluence 中的 Mermaid 源码编辑区。这里存放现状调研、交互方案和原型。

## 使用基线

2026 年 10 月 27 日至 11 月 23 日，平均每天约有 88 个独立账号打开 Mermaid 文本编辑器，工作日平均约 114 个。同期排名第二的 ZenUML（Sequence）约有 28 个独立账号每天打开。

数据来自 Mixpanel。统计覆盖 Confluence 生产环境，排除内部和测试站点，按墨尔本时间和 Atlassian 账号去重。直接打开或切换到 Mermaid 都计入，此口径衡量进入编辑器的用户数。
