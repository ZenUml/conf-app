Welcome to AsyncAPI for Confluence 🎉

Thanks for installing AsyncAPI for Confluence. Your team can now write, render, and share event-driven API specifications on Confluence pages — with the AsyncAPI Studio editor built in, and OpenAPI support included.

Your first spec, three steps

1. Insert a Macro

On any page, press / and pick AsyncAPI Spec.

2. Write Your Spec

Edit YAML in AsyncAPI Studio — the preview updates live.

3. Save and Share

Publish the page — the spec is versioned with it.
Get started →
 

What you can document

Three macros, one app:

ASYNCAPI

AsyncAPI Spec — create an event-driven API spec with the bundled AsyncAPI Studio editor.
OPENAPI

Render an OpenAPI / Swagger spec as interactive API docs — both formats, one app.
EMBED

Embed AsyncAPI Spec — reuse an existing spec on any other page, one source of truth.
