Welcome to ZenUML for Confluence 🎉

Thanks for installing ZenUML for Confluence Lite. Your team can now create flowcharts, sequence diagrams, free-form graphs, and interactive API docs — six diagram types, one app, right inside Confluence.

flowchart LR
  Draft --> Review
  Review -->|changes| Draft
  Review --> Publish

Your first diagram, three steps

1. Insert a Macro

On any page, press / and pick Diagram.

2. Create Your Diagram

Write text, or draw — the preview updates live.

3. Save and Share

Publish the page — the diagram is versioned with it.
See all six diagram types →
 

Have a particular diagram in mind?

Jump straight to the guide you need:

FLOWCHART

Map a process top-to-bottom or left-to-right with Mermaid — the same syntax GitHub renders — or PlantUML.
SEQUENCE

Describe how components or actors talk to each other, in plain text, with ZenUML sequence diagrams.
GRAPH

Draw free-form diagrams with the embedded DrawIO editor.
API DOCS

Render an OpenAPI / Swagger spec as interactive API docs, inline.
EMBED

Embed an existing diagram, graph or API spec on any other page — one source of truth.
