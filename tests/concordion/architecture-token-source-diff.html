Source Binding Engine: Stage 1 relocation evidence

This stage compares two source revisions. It can prove that a saved UTF-8 source address moved only through unchanged text. It produces relocation evidence only: it never confirms logical identity and never transfers or retains an Architecture Token binding. Those decisions are deliberately later stages.

A locator is an address in one revision, not an identity. When its exact byte span is entirely inside an unchanged diff hunk, Stage 1 records the corresponding new byte span at confidence 1.0. Any changed, invalid, empty, or duplicate saved locator is unresolved rather than guessed.

Stage boundary

This document covers Mermaid Flowchart source-address evidence only. It does not parse an identity, use Mermaid native IDs or fingerprints, compare candidates, assign matches, retain a binding, write Confluence content, call a backend, or create an index.
